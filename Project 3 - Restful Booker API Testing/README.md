Project Overview

Restful Booker is an APi that allows bookings to be created, viewed, updated and deleted. This project verifies that the API behaves according to its documentation.

What This Project Demonstrates

Test Case Planning: For test case planning, this project demonstrates that I can identify endpoint dependencies, determine the testing sequence and consider testing priority.  I'm also showing I can select test data based on documented requirements and plan positive and negative testing scenarios.  

Test Case Documentation: For test case documentation, this project demonstrates that I can provide another tester with everything they need to execute each test consistently.
